## Running the App

### Android
```
flutter run
```

### iOS (on macOS)
```
flutter run
```

### Web
```
flutter run -d chrome
```

## Building for Release

### Android APK
```
flutter build apk
```

### iOS (on macOS)
```
flutter build ios
```

### Web
```
flutter build web
```
